# かんじ手帳

手書きで漢字を書くときに、形をすぐ確認するためのシンプルなアプリです。
ひらがなを入力すると、漢字の候補を練習用のマス目（十字の補助線つき）に大きく表示します。

- 音声入力：スマホのキーボードのマイクボタンで入力
- 漢字をタップすると画面いっぱいに拡大
- 開くたびに空の状態から始まり、「リセット」ボタンで手動でも消去可能
- 送りがな付きの言葉（書く・美しい など）にも対応
- 辞書はページと一緒に配信するので、検索は通信なしで動きます

## 使い方

GitHub Pages を有効にすると、ブラウザから開けます。
（Settings → Pages → Branch: `main` / `/ (root)`）

## ファイル

- `index.html` … アプリ本体
- `dict.json` … ひらがな→漢字の辞書（約13万語）
- `tools/conv.py` … SKK辞書から `dict.json` を作るスクリプト
